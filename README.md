# spbt-site

Сайт **SPBT — Small Projects by Taiyo**, `https://spbt.pp.ua`.

Одна сторінка-слайдер: що вже працює, що можна замовити, як замовити,
контакти. Статика без збірки — HTML + CSS + ES-модулі, нуль залежностей,
нуль `npm install`. Хоститься на GitHub Pages.

## Структура

```
index.html          сім слайдів + футер (class="slides" — див. нижче)
404.html            сторінка помилки (noindex, звичайний документ без снапу)
CNAME               spbt.pp.ua
.nojekyll           Pages не проганяє файли через Jekyll
robots.txt · sitemap.xml
assets/
  css/base.css        токени, шрифти, ресет, утиліти
  css/layout.css      навбар, hero, секції, снап-слайди, футер
  css/components.css  кнопки, картки, плитки, горизонтальна доріжка, тизер
  css/spbt.css        те, що є лише тут (див. «Спільний код»)
  js/fx.js            фон-решітка, 3D-емблема, курсор
  js/motion.js        поява при скролі, тілт, магнітні кнопки, лічильники
  js/site.js          навбар, колесо-слайди, доріжка проєктів, boot
  img/                favicon, og, банер TANO, знімки кейсів
  fonts/*.woff2       Unbounded, Manrope, JetBrains Mono (самохост)
tools/
  check.test.mjs      18 тестів: node --test tools/check.test.mjs
  check.mjs           хелпери до тестів (палітра, дозволені хости)
  serve.mjs           локальний сервер на :4173
  shot.mjs            скріншоти через CDP
  og.html             джерело для assets/img/og.png (1200×630)
```

## Спільний код із портфоліо

`base.css`, `layout.css` і `components.css` — **побайтові копії** тих самих
файлів із `taiyo-portfolio`. Ті самі токени, той самий навбар, той самий
рушій слайдів, ті самі картки й плитки. Це зроблено свідомо: правку, зроблену
на одному сайті, можна перенести на другий простим копіюванням, без розбору
розбіжностей. Тому все, що потрібно **лише** цьому сайту, живе в `spbt.css`,
а не домішується в ті три файли.

`fx.js` і `site.js` розходяться з портфоліо в двох місцях, і обидва свідомі:

- герой показує **знак SPBT** із точок, а не гліф `</>` — той самий рушій
  (дві матриці обертання, перспектива, відштовхування від курсора), але фігура
  береться з полігону, а не з шрифту, тому чекати на завантаження Unbounded
  не потрібно;
- `initSlideWheel` у вузькому вікні, де слайд не влазить у екран, крокує на
  ~85% висоти вікна замість стрибка до наступної точки — інакше колесо
  перескакувало б через вміст, який видно лише скролбаром.

## Локальний перегляд

```bash
node tools/serve.mjs      # http://localhost:4173
```

Саме через сервер, а не `file://`: браузери блокують ES-модулі з `file://`
(CORS), тому `site.js` не завантажиться і блоки з'являться лише через 2.5 с,
коли спрацює failsafe у `<head>`. Верстка та шрифти при цьому цілі.

## Тести

```bash
node --test tools/check.test.mjs
```

Кожен тест закріплює рішення, яке легко скасувати випадково: закрита палітра,
самохостні шрифти, ліміт на вагу картинок, `rel="noopener"` на кожному
`target="_blank"`, живі `#якорі`, і — окремо — **заборона посилатися на
`ftl.if.ua`**, поки сайт ліцею не запущено.

## OG-картинка

`assets/img/og.png` рендериться з `tools/og.html`:

```bash
node tools/serve.mjs
node tools/shot.mjs <тека> 1200x630 http://localhost:4173/tools/og.html
```

Джерело лежить у `tools/`, а не в `scratch/`, саме тому що воно в репозиторії:
`scratch/` у `.gitignore`, і картинку, яку сайт віддає у соцмережі, не було б
чим перезібрати після клонування. `check.mjs` не бере `tools/` у перевірку
сторінок, тому цей файл не вважається сторінкою сайту.

## Домен

`CNAME` тримає `spbt.pp.ua` — рівно 11 байтів без BOM (тест перевіряє
побайтово: одного разу там уже був BOM, і `.trim()` його не бачив, бо U+FEFF
вважається пробілом).

`spbt.pp.ua` — вершина зони (`pp.ua` — публічний суфікс), тому в DNS стоять
`A`-записи GitHub Pages, а не `CNAME`. **HTTPS поки не ввімкнено.** Точні
записи, поточна перешкода й порядок дій — у приватних нотатках проєкту
(`docs/` у робочій теці, не в цьому репозиторії): цей файл віддається
публічно за адресою сайту.
